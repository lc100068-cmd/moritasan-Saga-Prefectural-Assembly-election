# セットアップ手順

所要時間の目安：30〜40分。プログラミングの知識はなくても、手順どおりに進めれば設定できます。

---

## 0. 事前に用意するもの

| もの | 理由 |
|---|---|
| **運営用の Google アカウント**（例：`morita.office.xxxx@gmail.com`） | メルマガの差出人・管理画面のログインに使います。個人のアカウントとは分けておくと、引き継ぎや複数人運用が楽です。 |
| GitHub アカウント | 公開サイトを無料で公開するために使います。 |
| 顔写真・プロフィール・政策・活動歴の原稿 | 管理画面から入力します。 |

> **ご本人・陣営の了承を必ず得てください。** 候補者名義のサイトとメルマガになるため、内容・運営者表示・差出人名はご本人（または事務所）の確認を経てから公開してください。

---

## 1. スプレッドシートと Apps Script を作る

1. 運営用アカウントで [Google スプレッドシート](https://sheets.new) を新規作成し、名前を「森田浩文 活動サイト」などにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 左の「ファイル」で、最初からある `コード.gs` の中身をすべて消し、このリポジトリの **`gas/Code.gs`** の内容を貼り付けます。
4. 「ファイル」の **＋ → HTML** で `Admin` という名前のファイルを作り（`.html` は自動で付きます）、**`gas/Admin.html`** の内容を貼り付けます。
5. 歯車アイコン（プロジェクトの設定）→ **「appsscript.json」マニフェスト ファイルをエディタで表示する** にチェック → 表示された `appsscript.json` を **`gas/appsscript.json`** の内容に置き換えます。
6. 💾 保存します。

## 2. 初期設定を実行する

1. エディタ上部の関数選択で **`setup`** を選び、▶ 実行 を押します。
2. 「承認が必要です」と出るので、運営用アカウントを選んで許可します。
   （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」で進めます。自分で作ったスクリプトなので問題ありません）
3. スプレッドシートに `settings` `profile` `policies` `history` `sns` `instagram` `posts` `subscribers` `queue` `send_log` のシートができていれば成功です。

## 3. ウェブアプリとして公開（デプロイ）する

1. Apps Script 右上の **デプロイ → 新しいデプロイ**。
2. 種類の選択（歯車）で **ウェブアプリ** を選びます。
3. 次のように設定して **デプロイ**：
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーします。

> 「全員」にするのは、サイトの登録フォームやメールの「配信停止」リンクを誰でも使えるようにするためです。
> 管理画面は、同じ URL を開いても**運営用アカウントでログインしているときだけ**表示されます（それ以外の人には「管理者専用です」と表示され、操作もできません）。

5. コピーした URL をブラウザで開くと **管理画面** が出ます。ブックマークしておいてください。

### コードを更新したとき
デプロイ → **デプロイを管理** → 鉛筆アイコン → バージョン「新バージョン」→ デプロイ。
（「新しいデプロイ」を作ると URL が変わってしまうので注意）

## 4. 公開サイトを GitHub Pages で公開する

1. このリポジトリの **`config.js`** を開き、`API_URL` に手順3の URL を貼ります。
   ```js
   API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
   ```
2. GitHub のリポジトリ → **Settings → Pages** → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存。
   - リポジトリが **非公開（Private）の場合、GitHub Pages は有料プラン**が必要です。公開リポジトリにするか、Netlify / Cloudflare Pages など別の無料ホスティングを使ってください（ファイルをそのままアップロードするだけで動きます）。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
4. 管理画面の「サイト情報」→ **公開サイトのURL** にこの URL を入れて保存します（メールの「サイトで読む」リンクに使われます）。

独自ドメイン（例：`morita-hirofumi.jp`）を使う場合は、ドメインを取得して GitHub Pages の Custom domain に設定します。

## 5. 内容を入力する

管理画面の **「サイト情報」** タブで次を入力・保存します（サイトへの反映は最大5分）。

- 基本情報：キャッチコピー、リード文、プロフィール本文、顔写真URL、事務所情報
- プロフィール項目 / 目指すこと / これまでの活動 / SNSリンク
- サイトに埋め込む Instagram 投稿：投稿ページの URL を貼るだけで埋め込まれます

**顔写真**：Google ドライブに置いた画像を使う場合は、「活動報告」タブの画像アップロードで一度アップロードし、出てきた URL を「顔写真のURL」に貼るのが簡単です。

> サイトの文章はスプレッドシートを直接編集しても反映されます。
> `data/site.json` は API が使えないときの予備表示用です。本番運用ではスプレッドシートの内容が優先されます。

## 6. 動作確認

1. 公開サイトのメルマガ欄から、自分のメールアドレスで登録してみる
2. 確認メールが届き、リンク → 「登録を完了する」で `subscribers` シートの状態が `active` になる
3. 管理画面で活動報告を書いて「公開」で保存 → サイトに出る
4. 「自分にテスト送信」で見た目を確認 → 「読者に配信する」

## 日々の使い方

1. 管理画面を開く → **活動報告・メルマガ** → ＋新しい活動報告
2. 日付・タイトル・本文・写真を入れ、状態を **公開** にして保存 → サイトに掲載
3. **自分にテスト送信** で確認 → **読者に配信する**

### メールの送信数の上限について
Apps Script からのメール送信には 1日あたりの上限があります（目安：無料の Gmail アカウントは **約100通/日**、Google Workspace は **約1,500通/日**）。
上限を超えた分は自動で「送信待ち」になり、**1時間ごとに自動で続きを送ります**。

読者が数百人を超えてきたら、次のどちらかを検討してください。
- 運営用アカウントを **Google Workspace**（月額数百円〜）にする
- 配信専用サービス（ブラストメール、配配メール、Mailchimp など）に移行する
  → 管理画面「読者」タブの **CSVダウンロード** で読者リストを移せます。

### 管理者を増やしたいとき
- 基本は **運営用アカウントを共有して**ログインしてください。
- Google Workspace の同じドメイン内のアカウントであれば、Apps Script の「プロジェクトの設定 → スクリプト プロパティ」の `ADMIN_EMAILS` にカンマ区切りで追加できます。
- 複数の Google アカウントに同時ログインしていると、管理画面が「管理者専用です」になることがあります。その場合はシークレットウィンドウ等でお試しください。
