# タスク1：デザイン性の高い政治家サイトのリサーチ

## 背景
- このリポジトリは、2027年佐賀県議会議員選挙（2027年4月2日告示／4月11日投票）に出馬予定の **森田浩文（もりた ひろふみ）** さんの活動サイトです。
- 今のデザイン（`index.html` / `assets/css/style.css`）は「ありきたりで垢抜けない」という評価です。
- リニューアルの参考にするため、**デザイン性の高い政治家・候補者・自治体首長などのサイト**を集めて分析してください。

## やること
1. Web検索で候補を **15件以上** 集め、その中から優れたものを **8〜12件** に絞る。
   - 日本の政治家サイトを中心に（国会議員・知事・市長・県議・市議・新人候補など、規模は問わない）。
   - 地方議員・新人候補の良い例を **最低3件** は入れる（今回の規模感に近いため）。
   - 海外の政治家・キャンペーンサイトも **2〜3件** 入れてよい（デザインの発想の参考として）。
   - 探し方の例：「政治家 ホームページ デザイン」「議員 公式サイト おしゃれ」「市長 公式サイト」「県議会議員 公式サイト」、Web制作会社の制作実績ページ、デザインギャラリーサイト（政治・選挙カテゴリ）など。
2. 選んだサイトごとに、Playwright で **PC幅（1280px）とスマホ幅（390px）のファーストビュー** をスクリーンショットする。
   - 保存先：`docs/research/design-refs/` （ファイル名は `01-pc.png` `01-sp.png` のように番号で）
   - 取得できないサイト（ネットワーク制限、ログイン必須など）は、無理せずURLと理由だけ記録する。
3. 分析結果を **`docs/research/design-references.md`** にまとめる。

## 出力の形式（design-references.md）
```
# 政治家サイト デザインリサーチ

## まとめ（先に結論）
- 優れたサイトに共通する特徴 5〜7個
- このサイトに取り入れるべきこと TOP5（具体的に）
- 避けるべきこと（ダサく見える原因）

## 参考サイト一覧
### 01. 〇〇〇〇（肩書き）
- URL:
- スクリーンショット: design-refs/01-pc.png / 01-sp.png
- 良いところ: （ファーストビュー、写真の使い方、文字組み、配色、余白、動き、情報の順番 など）
- 取り入れられるアイデア:
...

## 今のサイトとの比較
- 今のサイトの弱点（具体的に。例：「顔写真が仮画像」「見出しが全部同じ調子」）
- 改善の方向性 3案（例：A. 写真を大きく見せる誠実系、B. 地域の風景を使う親しみ系、C. タイポグラフィで見せるモダン系）
  - 各案の配色（カラーコード）、フォント（Google Fonts で使えるもの）、ファーストビューの構成
```

## 守ること
- **デザインの「考え方・パターン」を学ぶのが目的**です。特定サイトのレイアウト・画像・ロゴ・文章をそのままコピーする提案はしないこと。
- 政党カラーに寄りすぎる配色は避ける方向で（森田さんの所属政党は未確認のため）。
- スクリーンショットは分析用。公開サイトには使わない。
- 作業が終わったら、変更をコミットして現在のブランチにプッシュする。
- 最後に、ユーザーへ **日本語で** 「結論 TOP5」と「改善の方向性 3案」を短く報告する。
