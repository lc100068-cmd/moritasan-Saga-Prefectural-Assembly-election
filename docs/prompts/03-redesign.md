- 管理画面とメール配信（`gas/`）は **今回は触らない**。
- 参考資料：
  - `docs/research/design-references.md`（デザインリサーチ）

## やること
### 1. メルマガ機能を「保留」にする（消さずに隠す）
- `config.js` に `NEWSLETTER_ENABLED: false` を追加する。
- false のとき、メルマガのセクション・ナビの「メルマガ登録」・ヒーローの「活動報告をメールで受け取る」ボタンを非表示にする。
- 代わりの行動ボタンは「SNSをフォローする」「活動報告を見る」などにする。
- true に戻せば今の機能がそのまま復活するようにしておく。

### 2. デザインを作り直す
- ユーザーが選んだ方向性に沿って、配色・フォント・レイアウト・余白・写真の見せ方を作り直す。
- 特に直すところ：
  - ファーストビュー（名前・キャッチコピー・写真の迫力。サイトの印象はここでほぼ決まる）
  - 見出しまわりのメリハリ（全部同じ調子になっていないか）
  - 「目指すこと」「これまでの活動」を読んでもらえる見せ方
  - スマホでの見え方（閲覧者の多くはスマホ）
- 写真がまだない前提でも、ダサく見えないデザインにする（仮画像が目立たない構成、写真が入ったときに映える枠組み）。
- 特定サイトのレイアウト・画像・文章をそのまま真似しない。

### 3. 内容を反映する（確認済みの情報だけ）
- `morita-profile.md` の「サイトへの反映案」のうち **確度 ✅ のものだけ** を `data/site.json` に入れる。
- それ以外は【サンプル】のままにする。

## 守ること
- 告示前なので、「投票してください」「清き一票を」など **投票を依頼する表現は入れない**（事前運動になる）。
- 今の作り（`data/site.json` などから内容を読んで表示する仕組み）は維持する。将来、管理画面から更新できるように。
- 外部ライブラリは最小限に。読み込みが重くならないようにする。
- アクセシビリティ：文字と背景のコントラストを十分に、画像に alt、キーボードで操作できるように。
- 表示幅 1280px と 390px で横スクロールが出ないこと。

## 確認
- `python3 -m http.server` で起動し、Playwright で PC（1280px）・スマホ（390px）の全体スクリーンショットを撮って、崩れがないか自分で確認する。
- 修正前と修正後のスクリーンショットをユーザーに送る。
- コンソールエラーがないこと。
