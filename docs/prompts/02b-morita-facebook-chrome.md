# タスク2b：森田浩文さんの Facebook を Claude in Chrome で調べる

## 事前準備（ユーザーがやること）
1. Chrome に **Claude in Chrome（拡張機能）** を入れて、Claude と接続しておく。
2. その Chrome で **Facebook にログイン済み** にしておく（調べる人自身のアカウントでよい）。
3. Claude Code のセッションが Chrome を使えるようにしておく（デスクトップアプリ、または Chrome と連携したセッション）。
4. 貼り付ける文：

```
docs/prompts/02b-morita-facebook-chrome.md を読んで、その指示どおりに実行してください。
```

## 背景
- このリポジトリは、2027年佐賀県議会議員選挙（2027年4月2日告示／4月11日投票予定）に出馬予定の **森田浩文（もりた ひろふみ）** さんの活動サイトです。
- タスク2（`docs/prompts/02-morita-research.md`）の結果は `docs/research/morita-profile.md` にあります。そこでは Facebook・Instagram などの本文が読めず、SNS は未確認のままです。
- 森田さんは **吉野ヶ里町在住の前・吉野ヶ里町議（3期）／あいちゃん農園 代表／神埼市・吉野ヶ里町選挙区の県議選・自民党公認の新人**（佐賀新聞の報道）。Facebook に活動報告・経歴・出馬の思いが多く出ているはずなので、**ブラウザで開いて読み取る** のがこのタスクです。
- 集めた情報は、最終的に森田さんご本人・事務所の確認を経てからサイトに載せます。

## 最初にやること
1. `docs/research/morita-profile.md` を読む（すでに分かっていること、未確認の項目、同一人物の判定の根拠を把握する）。
2. Claude in Chrome を使う前に、スキル **`anthropic-skills:chrome-browser`** を読み、その手順（タブの扱い、サイトの許可、停止して確認する場面）に従う。
3. Chrome で **新しいタブ** を開いて作業する（ユーザーが開いている既存のタブは使わない・閉じない）。

## 調べること
| 探すもの | 見るところ |
|---|---|
| 本人のアカウント | Facebook 内検索「森田浩文 吉野ヶ里」「森田浩文 町議」「森田浩文 県議」。公式のページ（公人ページ）か個人のプロフィールか |
| あいちゃん農園のページ | 「あいちゃん農園」「吉野ヶ里 あいちゃん農園」 |
| 後援会のページ | 「森田浩文 後援会」 |
| 基本情報（公開されている範囲） | 「基本データ」「自己紹介」：出身地・学歴・職歴・肩書き・所属 |
| 出馬表明・活動 | 2026年2月25日前後（出馬表明）、それ以降の投稿。県議選への思い、公認、街頭活動、あいさつ回り |
| 町議時代の活動 | 一般質問、町の行事、消防団・交通安全・子どもクラブなどの活動 |
| 主張・政策 | よく出てくるテーマ、繰り返し使う言葉・フレーズ |
| ほかの発信先 | プロフィールや投稿に出てくる Instagram・X・YouTube・LINE・ブログ・公式サイトのURL |
| 写真の候補 | 使えそうな写真が載っている投稿のURL（**ダウンロードしない**。使う場合は本人に提供を依頼する） |

読む範囲の目安：**直近2年ぶんの投稿**を、新しいほうからスクロールして読む。それより古い投稿は、経歴を確認する必要があるときだけ開く。

## 守ること（重要）
- **同姓同名の別人に注意。** 次の点のうち **2つ以上** が合うアカウントだけ「本人」と判断する：吉野ヶ里町／吉野ヶ里町議／あいちゃん農園／県議選への出馬／地元の人との共通のつながり。迷ったら「要確認」にする。
- **見るだけにする。** 投稿・コメント・「いいね」・友達申請・フォロー・メッセージ送信・シェアは **一切しない**。ログイン済みのアカウントで操作するので、足跡が残る行為はしない。
- **私生活の情報は集めない。** 自宅の住所、家族・友人の個人名や顔写真、子どもが写った写真、健康・宗教・交友関係など、本人が政治活動として公表していない情報は対象外。友達リストは開かない。
- コメント欄に出てくる **ほかの人の名前・発言は記録しない**。
- **ログイン画面・本人確認（CAPTCHA、二段階認証、「ロボットでないことを確認」）・パスワード・支払い・個人情報の入力を求められたら、そこで止めて**ユーザーに報告する。入力や回避はしない。
- 「ログインが必要」で読めないものは、無理に回避せず「閲覧不可」として記録する。
- すべての情報に **出典URL（投稿のURL）と投稿日** を付ける。出典のない情報や推測は書かない。
- 投稿の文章は、**要点を自分の言葉でまとめる**。引用する場合は、短い一文だけ、日付とURLを付ける（サイトに載せるときは本人の了承を得て書き直す前提）。
- 確度を3段階で付ける：
  - ✅ 確認済み：本人の公式アカウントの投稿・プロフィール、または報道・公的情報と一致するもの
  - ⚠️ 要確認：出典が1つだけ、日付が古い、本人のアカウントかどうかが断定できない
  - ❓ 未確認：見つからなかった項目（空欄のまま）
- 調べた情報を **サイトのファイル（index.html / data/site.json / gas/）にはまだ反映しない**。

## 終わったら
- 変更をコミットして現在のブランチにプッシュする。
- ユーザーへ **日本語で**、見つかったアカウント・新しく分かったこと・「本人に確認したいこと」を短く報告する。
- Facebook でほとんど見つからなかった場合も、そのまま報告する（推測で埋めない）。
