# 公職選挙法まわりの注意点（運用メモ）

> これは運用上の注意をまとめたメモで、法的助言ではありません。
> 判断に迷う表現・運用は、**佐賀県選挙管理委員会**や、陣営の法務担当に事前に確認してください。

日程（2027年 佐賀県議会議員一般選挙）
- 告示日：**2027年4月2日（金）**
- 投票日：**2027年4月11日（日）**
- 管理画面の「サイト情報 → 選挙日程」に設定済み。日付で画面の注意表示と制限が自動で切り替わります。

---

## 告示前（〜2027年4月1日）＝政治活動期間

- 活動報告・政策の発信、メルマガ配信は **政治活動** として行えます。
- **「投票してください」「清き一票を」「当選させてください」など、特定の選挙での投票を依頼する表現は「事前運動」として禁止**されています。
  → 管理画面で、該当しそうな語句を含む記事を保存しようとすると警告が出ます（あくまで目安です）。
- 「立候補予定」「出馬表明」などの事実の報告は一般に可能ですが、表現は慎重に。

## 選挙期間中（2027年4月2日〜4月10日）

**ウェブサイト・SNS**
- 候補者・支援者ともにウェブサイトや SNS で選挙運動ができます。
- サイトには **連絡先（メールアドレス等）の表示が必要** です → フッターに事務所のメールアドレスを必ず入れてください（「サイト情報 → 問い合わせ用メールアドレス」）。

**電子メール（メルマガ）** ※ここが一番注意が必要です
- 選挙運動用の電子メールを送れるのは **候補者本人と政党等だけ** です。**支援者（第三者）が自分の名前で送ることはできません。**
  → メルマガは **森田さん本人（または事務所）名義** で送ってください。差出人名・運営用アカウントもその前提で設定しています。
- 送れる相手は、**事前に自分から送信を求めた／同意した人** だけです。
  → 登録フォームの同意文・登録日時・確認日時を `subscribers` シートに記録しています（**この記録は保存義務があるので消さないでください**）。
- メールには次の表示が必要です → 選挙期間中は **自動で挿入** されます。
  - 選挙運動用電子メールである旨（件名に【選挙運動用電子メール】）
  - 送信者の氏名
  - 送信拒否の通知ができる旨と、通知先のメールアドレス
- 受信者に **メールの転送をお願いしない** でください（転送された先は同意を得ていないため）。
- 選挙運動用電子メールを **印刷して配る** ことはできません。

## 投票日当日（2027年4月11日）

- **選挙運動は一切できません。** サイトの更新・メール配信・SNS投稿は行わないでください。
- サイトは前日までの内容をそのまま表示しておくことはできます。
  → 管理画面は当日、保存・配信ボタンが自動で無効になり、送信待ちのメールも止まります。

## 選挙後

- 当選・落選に関するお礼のあいさつ（「ご投票ありがとうございました」など）には制限があります。
  インターネットでのお礼は一定の範囲で認められていますが、メール配信の可否と表現は事前に選挙管理委員会へ確認してください。

## その他

- **18歳未満の人は選挙運動ができません**（SNS のシェアや拡散のお願いも含む）。
- 有料のインターネット広告（バナー広告など）を候補者名で出すことは原則禁止です。
- メルマガ全般（選挙期間外を含む）は「特定電子メール法」の対象にもなりうるため、同意の記録・送信者表示・配信停止方法の明記を常に行っています。
